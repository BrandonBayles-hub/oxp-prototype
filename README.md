# Janet POC

Proof-of-concept for the AI-native multifamily platform. Navigable UI with all major pages and mock data.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). You’ll be redirected to **Getting Started**. Use the sidebar to open Command Center, Escalations, Performance, Agent Roster, Workforce, Workflows, Trainings & SOP, Voice, Tools, and Governance.

## Build

```bash
npm run build
npm start
```
